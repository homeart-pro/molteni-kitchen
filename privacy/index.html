1. Состав обрабатываемых данных

Оператор обрабатывает персональные данные, предоставленные пользователем через формы на Сайте:

  • имя;
  • номер телефона;

2. Цели обработки

  • обработка заявок на консультацию по коллекциям Molteni&C;

3. Правовые основания

Обработка персональных данных осуществляется с согласия пользователя, предоставляемого путём заполнения формы на Сайте и проставления отметки о согласии.

4. Сроки хранения

Персональные данные хранятся не дольше срока, необходимого для целей их обработки, либо до момента отзыва согласия пользователем.
